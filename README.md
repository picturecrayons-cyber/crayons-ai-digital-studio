# StreamVista — AI Media Production OS

An independent AI-assisted media production workspace, beginning with film localization and versioning.

## Product boundaries
- StreamVista: production projects, localization jobs, subtitle and dubbing drafts, QC, and deliverable preparation.
- Crayons Bridge: sole system for rights, licensing, buyer marketplace, and distribution authorization.
- Crayons LOOP: consumer OTT and TVOD.

## First workflow
1. Create a localization project.
2. Select a source video clip up to 10 minutes.
3. Choose source and target languages.
4. Prepare subtitle and dubbing drafts.
5. Run technical QC and human review.
6. Prepare verified deliverables.

## Current implementation status
- React + TypeScript + Vite foundation.
- Dark cinematic production dashboard.
- Browser-side project creation and 10-minute video-duration validation.
- Pipeline stages displayed as workflow structure.
- GitHub Actions typecheck and build workflow added.
- Backend upload, persistence, transcription, translation, dubbing, payment, QC, and delivery are NOT CONNECTED / NOT VERIFIED.

## Commercial and security rules
- No mock claims of completed AI processing, payment capture, QC, or delivery.
- Prefer free/open-source processing components; verify each dependency, model, voice, and asset licence for commercial use.
- No secrets in client code or repository.
- No production deployment or paid infrastructure changes without explicit approval.
- Quote-based pilot pricing until real processing, storage, review, and delivery costs are measured.
